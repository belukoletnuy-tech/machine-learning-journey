# ⚙️ Linear Regression From Scratch

Taking my Machine Learning journey one step further!

In this project, I implemented my own Linear Regression model to better understand how Machine Learning works under the hood.

## 🧠 What I Learned

- How Linear Regression works internally
- How a model calculates predictions and errors
- The concept of a loss function
- How Gradient Descent minimizes errors
- How Stochastic Gradient Descent (SGD) updates model parameters
- How weights and bias are adjusted during training

## 💡 Key Takeaway

Instead of just using ready-made ML algorithms, I explored the mathematics and logic behind them.

This helped me understand **what actually happens when a model learns**.
